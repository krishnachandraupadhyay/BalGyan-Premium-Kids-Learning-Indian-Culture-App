# 🌟 BalGyan — Premium Kids Learning & Indian Culture App (बालज्ञान)

> **"Picture → Interaction → Voice → Learning → Reward"**  
> A complete, premium-quality, highly interactive educational platform for children aged **3–8 years**.

---

## 🚀 Key Features

* 🔤 **English Adventure**: A–Z Capital and Small letters with **130+ distinct structured words (5+ words per letter)** with Hindi meanings, phonetics, audio, and random word rotation.
* 🕉️ **Hindi Garden (हिंदी वाटिका)**: Complete Swar (अ से अः) and Vyanjan (क से ज्ञ) with bilingual voice pronunciation (*"अ से अनार, अनार means Pomegranate"*).
* 🔢 **Number World**: 1 to 100 counting with interactive Touch & Count item popping and visual question quizzes.
* ➕ **Math Lab**: Visual Addition, Subtraction, Multiplication, and Division using fruit and toy counters.
* 🧗 **Table Mountain (पहाड़ा पर्वत)**: Gamified mountain climbing answering multiplication tables from 2 to 20 to reach the summit flag 🚩.
* 🕉️ **Sanskrit Gurukul (संस्कृत गुरुकुल)**: 35+ Sanskrit vocabulary words with Devanagari, English transliteration, Hindi meaning, and sacred Shlokas (*Gayatri Mantra, Saraswati Vandana, Guru Vandana*).
* 🇮🇳 **Bharat Explorer**: 10 National Symbols of India, Cultural Wonders, Monuments, Classical Dances, and respectful **Jana Gana Mana** & **Vande Mataram** player.
* 🪔 **Indian Festivals & Good Habits**: 8 Indian festivals with interactive mini-games and 10 Good Habits with moral choice dilemmas (*Help vs Ignore*).
* 📖 **Story World**: 5 illustrated multi-page interactive stories with morals and post-story quizzes.
* ✍️ **Tracing Canvas**: HTML5 canvas drawing for English letters, Hindi letters, and numbers.
* 🎮 **Arcade & Games Hub**: Bubble Pop letter game and Memory Match cards.
* 👤 **Avatar Studio & Shop**: Customizable cartoon mascots (Chintu Tiger, Golu Elephant, Meera, Kabir, Pari Peacock) unlockable with earned coins.
* 📊 **Parent Dashboard & Admin CMS**: Protected PIN gate, analytics, progress tracking, and dynamic content editor.
* 📱 **Mobile & Android Ready**: Capacitor Android native project & Progressive Web App (PWA) support.

---

## 🛠️ Tech Stack

* **Frontend**: React 18, Vite
* **Styling**: Vanilla CSS with custom Design Tokens, animations, glassmorphism, and responsive layouts
* **Icons & Confetti**: Lucide React, Canvas Confetti
* **Audio & Speech**: Web Audio API Synthesizer & Web Speech API (Dual English & Hindi)
* **Mobile Runtime**: Capacitor Android

## 🏃 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run local dev server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build Web Production Bundle
```bash
npm run build
```

### 4. Android Native Project
The native Android project is located in `/android`.
Open `/android` in **Android Studio** and click **Build ➔ Build APK(s)**.
